# Fotor for OpenCode Desktop / CLI

This repository is being prepared for the Fotor plugin for OpenCode v2.

**The default branch is not an installable plugin yet.** It currently contains
repository setup material. Wait for a verified package channel before using
this repository with `opencode plugin add`.

The planned package is `@fotor-ai/opencode-fotor-plugin`, with Git and npm
installation sources. It connects to the Fotor MCP service to create images,
video and audio. OpenCode v1 is outside the supported scope.

Publication tooling is reviewed separately from the installable package.
No plugin release is announced by this repository initialization.
